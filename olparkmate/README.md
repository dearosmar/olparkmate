# 올팍메이트 (OlparkMate)

> 외국인 관람객을 위한 다국어 올림픽공원 공연 동행 가이드
> A multilingual concert companion for international visitors to Seoul Olympic Park

**2026년도 한국체육산업개발(주) 공공데이터 활용 경진대회 출품작**

- 🔗 **웹 데모:** https://dearosmar.github.io/olparkmate/
- 🎨 **Figma 프로토타입:** https://www.figma.com/design/4GDj1eA2RxmUsMl6Tif5GI

> ⚠️ 현재 데모의 공연명·수치는 **공공데이터 응답 형식에 맞춘 샘플 데이터**입니다. 실제 API 연동은 2027년 1~2월에 진행할 예정입니다.

## 왜 만들었나요

KSPO DOME을 비롯한 올림픽공원 공연장에는 해외 K-팝 팬이 많이 찾아옵니다. 하지만 공연 당일에 필요한 주차·혼잡·교통·유실물 정보는 대부분 한국어로만 흩어져 있습니다. 그래서 외국인 관람객은 "몇 시에 가야 하는지", "끝나고 무사히 돌아갈 수 있는지"를 판단하기 어렵습니다.

올팍메이트는 기관이 개방한 공공데이터를 엮어 이 판단을 **영어·중국어·일본어·한국어**로 도와줍니다.

## 주요 기능

| 화면 | 기능 | 활용 데이터 |
|---|---|---|
| **Events** | 다국어 공연 캘린더, 다가오는 공연 알림 | 영문 공연정보, 대관정보 |
| **Forecast** | 공연·요일·날씨별 혼잡 예보, 추천 도착 시간, 알림 | 차량입출차·공연·날씨 연계 데이터, 기상청 단기예보 |
| **Live** | 출입문별 주차 혼잡도, 지하철 도착, 퇴장 시간 비교 | 실시간 주차현황, 주차장 혼잡도, 서울시 지하철 실시간 도착정보 |
| **Lost & Found** | 다국어 유실물 검색, 직원에게 보여주는 한국어 문의 카드 | 유실물 정보 |
| *(2단계)* 3D 미리보기 | 공연장 구조·출입구 미리 보기 | 공연장 실감형 콘텐츠 |

## 활용 공공데이터

**한국체육산업개발(주) (공공데이터포털 data.go.kr)**
1. 영문 공연정보
2. 올림픽공원 차량입출차, 공연, 날씨정보 등 연계 데이터
3. 실시간 주차현황
4. 주차장 혼잡도 정보
5. 올림픽공원 및 미사경정공원 유실물 정보
6. 올림픽공원 대관정보
7. 올림픽공원 공연장 실감형 콘텐츠 (2단계)

**타 기관 공동활용:** 기상청 단기예보, 서울시 지하철 실시간 도착정보, 한국관광공사 다국어 관광정보(TourAPI)

## 시스템 구성 (계획)

```
[data.go.kr 공공데이터 API]
        │  주기적 수집 (실시간 주차: 공연일 5분 / 공연·대관·유실물: 1일)
        ▼
[수집 서버 + DB 캐시] ──► [혼잡 예보 모듈]  공연 유무 × 요일 × 시간대 × 날씨별 입차량 통계
        │                      │
        ▼                      ▼
[번역 파이프라인]  고정 용어집(공연장·출입문 이름) → 기계번역 → 직접 검수
        │
        ▼
[모바일 웹]  설치 없이 QR로 접속   +   [iOS 앱 (SwiftUI)]  푸시 알림·위젯
```

## 혼잡 예보 방식

- 연계 데이터의 시간대별 입차 대수를 공연일/비공연일, 요일, 날씨(강수 여부·기온대)로 나눠 평균과 상위 구간을 계산합니다.
- 주차장 혼잡도 등급(원활·혼잡·만차)과 같은 시간대를 맞춰 보며 등급 기준을 보정합니다.
- 차량 입출차는 보행 인파의 **간접 지표**이므로, 화면에는 실제 인원수가 아닌 "상대적 혼잡도"로 표시합니다.

## 데모 실행

빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

```bash
git clone https://github.com/dearosmar/olparkmate.git
cd olparkmate
open index.html        # 또는 브라우저로 파일 열기
```

샘플 데이터는 `index.html` 안의 `DATA` 객체와 `data/sample.json`에 있으며, 각 항목은 원천 공공데이터의 필드 구조를 따릅니다.
